# 性能测试类型清单

> Day 1 学习笔记 · 6 种测试类型 + 目的 + 关注指标

---

## 一、6 种性能测试类型

| 测试类型 | 目的 | 方法 | 关注指标 | 图示 |
|----------|------|------|----------|------|
| 基准测试 (Benchmark) | 建立性能基线 | 低负载运行一段时间 | RT、TPS 基线值 | ──────── |
| 负载测试 (Load Test) | 验证预期负载下的性能 | 逐步加压到目标负载 | RT、TPS、错误率 | ╱──────╲ |
| 压力测试 (Stress Test) | 找到系统极限 | 持续加压直到崩溃 | 极限 TPS、崩溃点 | ╱──╱──╲ |
| 稳定性测试 (Soak Test) | 验证长时间运行稳定性 | 中等负载跑几小时/天 | 内存泄漏、资源耗尽 | ──────── (长时间) |
| 尖峰测试 (Spike Test) | 验证突发流量处理能力 | 突然加大量用户再撤掉 | 恢复能力、错误率 | ╱╲╱── |
| 容量测试 (Volume Test) | 大数据量下的性能 | 准备大量数据后测试 | 查询性能、存储性能 | 数据驱动 |

---

## 二、各类型详细说明

### 1. 基准测试 (Benchmark Test)

```
VU
 │
10├────────────────────────
 │
 └──────────────────────────→ 时间
```

- **目的**：建立性能基线，作为后续对比的参照
- **方法**：固定低负载（如 10 VU），稳定运行一段时间（如 1 分钟）
- **关键**：跑 3 次取稳定值，消除波动
- **产出**：基线数据表（TPS、P95、P99、错误率）

### 2. 负载测试 (Load Test)

```
VU
 │
50├────────────────────────
 │ ╱                      ╲
20├╱                        ╲
 │                          ╲
 0└──1m──────3m──────1m──→ 时间
   爬升    稳定     下降
```

- **目的**：验证预期负载下系统能否达标
- **方法**：逐步加压到目标 VU，保持一段时间，再逐步下降
- **关键**：三段式（爬升-稳定-下降），模拟真实用户流量
- **阈值**：通常设置 P95 < 500ms，错误率 < 1%

### 3. 压力测试 (Stress Test)

```
VU
 │
500┤                     ╲
 │                  ╱
300┤               ╱
 │          ╱
200┤     ╱
 │   ╱
100┤╱
50┤
 └──1m──1m──1m──1m──1m──30s→ 时间
```

- **目的**：找到系统性能天花板
- **方法**：持续加压直到系统崩溃或 TPS 不再增长
- **关键**：不设阈值，看能撑到多少
- **产出**：极限 TPS + 对应 VU 数 + 崩溃点

### 4. 稳定性测试 (Soak Test)

```
VU
 │
20├──────────────────────────────
 │                              (几小时/几天)
 └──────────────────────────────→ 时间
```

- **目的**：发现内存泄漏、连接泄漏等长时间问题
- **方法**：中等负载长时间运行
- **关键**：观察 RT 是否逐渐升高、内存是否持续增长
- **注意**：本地学习跑 10-30 分钟，正式测试跑几小时

### 5. 尖峰测试 (Spike Test)

```
VU
 │
200┤     ╱╲╱──
 │    ╱  ╲
10├──╱    ╲────────────
 │
 └──30s─10s─30s─20s─1m→ 时间
   正常  尖峰  持续  回落  恢复
```

- **目的**：验证突发流量下系统的弹性和恢复能力
- **方法**：突然加大流量，持续一会儿，快速回落
- **关键**：尖峰期间错误率 + 尖峰后恢复速度

### 6. 容量测试 (Volume Test)

- **目的**：大数据量下的性能表现
- **方法**：先灌入大量数据（如 100 万条），再测试
- **关键**：查询性能是否随数据量增长而下降
- **典型场景**：分页查询深翻页、大表聚合统计

---

## 三、测试类型选择矩阵

| 场景 | 推荐类型 | 原因 |
|------|----------|------|
| 上线前验证 | 负载测试 | 验证预期负载达标 |
| 容量规划 | 压力测试 | 找到极限，规划资源 |
| 长期运行 | 稳定性测试 | 发现泄漏问题 |
| 促销/秒杀 | 尖峰测试 | 验证突发流量 |
| 建立基线 | 基准测试 | 后续对比参照 |
| 数据增长 | 容量测试 | 验证大数据量性能 |

---

## 四、一句话总结

> 基准测试建基线，负载测试验达标，压力测试找极限，稳定性测试查泄漏，尖峰测试验弹性，容量测试看数据——六种类型覆盖从基线到极限、从短时到长时的全方位性能验证。
